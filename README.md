# Number Guessing Game

A browser-based game where you guess a random number between 1 and 100 in 10 attempts or less.

## How to Play

1. Open `troubleshooting.html` in a web browser
2. Guess a number between 1 and 100
3. Get feedback if your guess is too high or too low
4. Find the number within 10 turns to win

## Features

- Real-time feedback on guesses
- Guess tracking
- Game reset functionality

Built with HTML, CSS, and vanilla JavaScript.
